# Ankita Pradhan Portfolio

A single-page, responsive portfolio built with only:

- `index.html`
- `index.css`
- `index.js`
- `assets/RESUME_ANKITA_PRADHAN.pdf`

## Run locally

1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. No build process or backend is required.

## GitHub Pages

1. Create a GitHub repository.
2. Upload the extracted files/folders, keeping the structure exactly the same.
3. Go to **Settings → Pages**.
4. Select the branch containing `index.html` (usually `main`) and the root folder `/`.
5. Save and open the GitHub Pages URL.

The resume download buttons point to:

`assets/RESUME_ANKITA_PRADHAN.pdf`

Keep the `assets` folder in the same location relative to `index.html`.

## Notes

- The site is designed as a dark steel-blue, professional/futuristic interface.
- Navigation uses hash anchors and becomes a hamburger menu on mobile.
- The page includes responsive layouts, smooth scrolling, reveal animations, a technical console-style hero panel, and a highlights carousel.
- No external JavaScript library is required. Google Fonts are loaded from CDN when internet access is available.
